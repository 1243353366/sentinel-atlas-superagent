# Sentinel Atlas Memory

- Treat “zombie database” as an inert quarantine vault: store failure metadata, hashes, and safe snapshots; never replay payloads.
- Synthetic scenarios are deterministic fixtures only. They do not download, execute, modify, or network to anything.
- Game scoring rewards evidence connections, defensible uncertainty, mitigation quality, and explanation.
- The model may propose learning candidates, but permissions and policy are not learnable. Promotion requires regression validation and human approval.
- TiDB rejected a JSON-like text default in the progression migration; the live table was created with `unlocked` as a required text field and the schema was corrected.
